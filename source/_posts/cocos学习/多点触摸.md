# Cocos Creator 2.x 多点触摸笔记（Multi-touch）

## 1. 多点触摸概念

在 Cocos Creator 中，多点触摸可以让你的游戏同时响应多个手指触控事件，常用于：

* 双指缩放（pinch zoom）
* 两指旋转
* 多点拖动或复杂手势

默认 **多点触摸是开启的**，通过 `cc.macro.ENABLE_MULTI_TOUCH` 控制：

```ts
// 默认开启
cc.macro.ENABLE_MULTI_TOUCH = true;
```

* **单点触摸模式**：只处理第一个手指触摸事件，其他触摸忽略
* **多点触摸模式**：处理所有手指触摸事件

---

## 2. 常用触摸事件

Cocos Creator 的 `cc.Node` 可以监听以下触摸事件：

| 事件类型          | 描述              |
| ------------- | --------------- |
| `touchstart`  | 手指刚按下           |
| `touchmove`   | 手指移动            |
| `touchend`    | 手指抬起            |
| `touchcancel` | 系统取消触摸（例如来电、弹窗） |

**事件回调参数：** `event: cc.Event.EventTouch`

* `event.getLocation()` → 获取触摸点屏幕坐标
* `event.getDelta()` → 相对于上次触摸移动的位移
* `event.getTouches()` → 获取当前所有触摸点（多点触摸时使用）
* `event.getID()` → 获取触摸点唯一 ID

---

## 3. 单点触摸示例

```ts
const { ccclass, property } = cc._decorator;

@ccclass
export default class SingleTouch extends cc.Component {

    onLoad() {
        // 单点触摸
        this.node.on(cc.Node.EventType.TOUCH_START, this.onTouchStart, this);
        this.node.on(cc.Node.EventType.TOUCH_MOVE, this.onTouchMove, this);
        this.node.on(cc.Node.EventType.TOUCH_END, this.onTouchEnd, this);
    }

    onTouchStart(event: cc.Event.EventTouch) {
        const pos = event.getLocation();
        console.log('单点触摸开始', pos);
    }

    onTouchMove(event: cc.Event.EventTouch) {
        const delta = event.getDelta();
        this.node.x += delta.x;
        this.node.y += delta.y;
    }

    onTouchEnd(event: cc.Event.EventTouch) {
        console.log('单点触摸结束');
    }
}
```

## 4. 多点触摸示例

```ts
const { ccclass, property } = cc._decorator;

@ccclass
export default class MultiTouchExample extends cc.Component {

    onLoad() {
        // 确保多点触摸开启
        cc.macro.ENABLE_MULTI_TOUCH = true;

        this.node.on(cc.Node.EventType.TOUCH_START, this.onTouchStart, this);
        this.node.on(cc.Node.EventType.TOUCH_MOVE, this.onTouchMove, this);
        this.node.on(cc.Node.EventType.TOUCH_END, this.onTouchEnd, this);
        this.node.on(cc.Node.EventType.TOUCH_CANCEL, this.onTouchCancel, this);
    }

    onTouchStart(event: cc.Event.EventTouch) {
        const touches = event.getTouches();
        touches.forEach(t => {
            const pos = t.getLocation();
            console.log('多点触摸开始 ID:', t.getID(), '位置:', pos);
        });
    }

    onTouchMove(event: cc.Event.EventTouch) {
        const touches = event.getTouches();
        touches.forEach(t => {
            const delta = t.getDelta();
            console.log('ID:', t.getID(), '移动位移:', delta);
        });
    }

    onTouchEnd(event: cc.Event.EventTouch) {
        console.log('触摸结束 ID:', event.getID());
    }

    onTouchCancel(event: cc.Event.EventTouch) {
        console.log('触摸取消 ID:', event.getID());
    }
}
```

### 🔹 说明

1. `getTouches()` 返回当前所有活跃触摸点
2. `getID()` 用于区分不同手指
3. 多点触摸常用配合 **双指缩放** 或 **旋转** 手势

## 5. 常见手势处理思路

* **双指缩放**：

```ts
if (touches.length === 2) {
    const pos1 = touches[0].getLocation();
    const pos2 = touches[1].getLocation();
    const distance = pos1.sub(pos2).mag();
    // 用 distance 判断缩放比例
}
```

* **旋转手势**：

```ts
const delta = touches[0].getLocation().sub(touches[1].getLocation());
const angle = Math.atan2(delta.y, delta.x) * 180 / Math.PI;
this.node.rotation = angle; 
```

---

## 6. 注意事项

1. `cc.macro.ENABLE_MULTI_TOUCH` 必须在脚本初始化之前设置，否则默认多点触摸开启
2. 多点触摸会影响事件顺序：每个触摸点都会触发对应事件
3. `touchcancel` 在系统中断触摸时触发（例如弹窗、系统手势）
